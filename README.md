## Tech Stack

- **React**
- **TypeScript**
- **Tailwind CSS**
- **GSAP**
- **Lucide Icons**

## Getting Started

### Installation

1. Clone the repository

```bash
git clone https://github.com/rohit-yadavv/diskovalist-assignment-2
```

2. Install dependencies

```bash
npm install
# or
yarn
```

3. Start the development server

```bash
npm run dev
# or
yarn dev
```
